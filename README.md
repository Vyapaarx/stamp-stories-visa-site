# Stamp Stories Visa Services Website

Production-ready static landing page for Stamp Stories Visa Services.

## Included
- Mobile-first responsive landing page
- WhatsApp and call lead CTAs
- Lead form -> WhatsApp message flow
- SEO meta tags + LocalBusiness schema
- robots.txt and sitemap.xml

## Project Files
- `index.html`
- `styles.css`
- `script.js`
- `robots.txt`
- `sitemap.xml`

## Deploy on GitHub Pages (Vyapaarx)

### Recommended repo name
- `Vyapaarx.github.io`

### Steps
1. Create a new public repository named `Vyapaarx.github.io` in the Vyapaarx account.
2. Upload all project files from this folder to the repository root.
3. Go to repository Settings -> Pages.
4. Under Build and deployment, set Source to Deploy from a branch.
5. Select Branch: `main` and Folder: `/ (root)` and save.
6. Wait 1-3 minutes and open `https://vyapaarx.github.io/`.

## Pre-Launch Checklist
- Replace Instagram URL if needed
- Verify phone and WhatsApp number
- Submit `https://vyapaarx.github.io/sitemap.xml` in Google Search Console
- Test on mobile (Chrome + Safari)

## Notes
- If the website is hosted on a different domain, update these files:
  - `index.html` (canonical + og:url + schema url)
  - `robots.txt` (sitemap URL)
  - `sitemap.xml` (loc URL)
